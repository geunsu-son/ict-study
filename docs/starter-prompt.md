## 권장 (파일 첨부)

아래를 복사하고, 채팅에 `AGENTS.md`와 `docs/conversation-context.md`를 첨부하세요.

```
이 repo는 ICT 실습 수첩이다. 매매 실행이 아니라 체크리스트 학습 사이트다.

@AGENTS.md 와 @docs/conversation-context.md 를 읽고, 이후 질문·수정은 그 합의를 기준으로 답해라.

나는 ICT 초보다. 한국어로, 용어는 한 줄로 풀어라. 투자 조언·수익 주장은 하지 마라.

이 대화에 이전 채팅이 없어도, conversation-context에 적힌 영상 규칙(차트제로 진입/SL/TP)과 원전 필터(킬존·실버불릿·OTE·P/D), 학습 순서 01–06을 기억한 것처럼 답하면 된다.
```

## 첨부 없이 텍스트만

파일을 못 붙일 때는 이것만 붙여도 됩니다.

```
이 repo는 「ICT 실습 수첩」이다. 정적 HTML, Cloudflare Pages용. 주문·시세 API 없음.

먼저 AGENTS.md 와 docs/conversation-context.md 를 읽어라. 그게 나와의 이전 대화 메모다.

요약:
- 나는 ICT를 처음 배운다.
- 시작은 유튜브 차트제로 영상(https://youtu.be/6_4pkXiAy_c)의 BOS/초크, FVG, 오더블록, 진입=FVG 50%+확인 캔들, SL=장대 끝, TP=1:2 또는 반익 후 본전.
- 그다음 원전 필터를 순서대로: 프리미엄/디스카운트 → 킬존 → OTE → 실버불릿.
- 사이트는 그 순서로 스텝이 열리고, 내가 「익숙함」을 눌러야 다음으로 간다. 실전 수첩은 언제든 본다.
- 한국어, 초보 톤. 투자 조언 금지. Pine/자동매매는 다른 repo(trading-to-fire) 일이다.

이후 질문은 이 맥락을 유지하고, 문서를 고치면 conversation-context와 페이지가 어긋나지 않게 같이 맞춰라.
```
